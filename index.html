Teaching notes, data and references

How to use the lesson

Use Process animation for intuition. Use Full calculations to write down the arithmetic. Explore C and γ fits small SVM models in your browser. Pause at any scene and ask students to predict the next change.

The eight-point linear dataset is a deliberately simple teaching example. Features have arbitrary, comparable units. The lift z = x₁² + x₂² demonstrates feature engineering. It is distinct from the three-coordinate polynomial feature map in the worked kernel example.

Candidate boundaries and the widening-margin sequence illustrate the geometry. They are not optimizer iterations. Explore mode solves the SVM dual numerically, so its boundaries respond to the data and parameters.

Mathematical details

Linear example: w = (0.5, 0.5), b = −3. Support vectors: N3 = (2,2), P1 = (4,4). Both dual coefficients are 0.25. One-sided margin = √2, full width = 2√2.

Soft-margin objective: ½‖w‖² + C Σξᵢ, with yᵢf(xᵢ) ≥ 1 − ξᵢ and ξᵢ ≥ 0. The small deterministic browser solver uses sequential minimal optimization. Dashed contours indicate f = −1 and f = +1. Their geometric width formula applies to the linear feature space.

References: SVM user guide, RBF parameters, and your Chapter 2_7 SVM slides. No external libraries or network connection are needed for this animation.
